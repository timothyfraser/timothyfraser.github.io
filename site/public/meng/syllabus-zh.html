📋 硕士项目教学大纲

六个硕士团队项目，构建大数据与人工智能系统，用以测量并追踪城市与环境系统中的各项结果——空气质量、拥堵收费、出行网络与灾害韧性。

2026  项目导师：Timothy Fraser 博士，康奈尔大学系统工程助理教学教授。

项目概览

构建大数据与人工智能系统，用以测量并追踪城市与环境系统中的各项结果——空气质量、拥堵收费、出行网络与灾害韧性。本年度共有六个硕士团队项目，每个项目都有自己的团队、自己的注册课号和自己的产品。每个项目都要交付一份报告以及一个可运行的工具。

项目领域 排放、交通运输、空气质量、社会基础设施、可靠性、传感器、数据通信、可视化、系统架构、数据库、仪表板、算法
项目关键词 人工智能；自动化报告；仪表板；Web 系统开发；API；排放；因果推断；GIS；网络科学；智能体 AI；开放数据

六个项目

SYSEN 5900-648 课程编号 — 🚗 MOVESAI

基于 MOVESAI 的人工智能排放报告系统（AI-Powered Emissions Reporting Systems with MOVESAI）

机器学习仪表板排放

人工智能能否以足够快的速度复现一个重量级的 EPA 排放模型，让任何城市都能在线使用？

交通运输是温室气体和空气污染的主要来源之一，但用于估算它的模型运行缓慢，地方机构也难以使用。你将构建人工智能与机器学习系统，复现 EPA 的 MOVES 排放模拟器，并通过高速 API 和仪表板对外提供服务——这样城市就能在线估算并报告其交通排放，而无需运行完整模型。工作内容涵盖机器学习、API 设计、前端仪表板，以及随之交付的报告。

选课名额：5 名学生 代理模型 → 仪表板 → 报告
SYSEN 5900-662 课程编号 19053 🏙️ 城市空气

基于 CIVIC 的城市空气质量与交通数据系统（Urban Air Quality and Traffic Data Systems with CIVIC）

空气质量交通运输因果推断

当一座城市向进入市中心的驾驶者收费时，空气真的变干净了吗——又是谁从中受益？

当一座城市改变人们的出行方式——拥堵收费、新建公共交通、道路改造——空气真的变干净了吗，又是为谁变干净的？你将构建 CIVIC 背后的数据系统：整合来自纽约、伦敦、斯德哥尔摩等城市的空气质量、公共交通与交通流量数据，然后运用因果推断来测量政策如何改变污染与出行。工作内容涵盖数据工程、面板数据库、统计学，以及向政策受众传达研究结果。

选课名额：5 名学生 数据 → 整合 → 报告
SYSEN 5900-663 课程编号 19054 🏘️ 社会基础设施

社会基础设施与应急出行（Social Infrastructure & Emergency Mobility）

GIS城市韧性应急管理

邻里聚集的场所，能否预测一座城市在灾害中的存续能力？

社会基础设施更为密集的城市——公园、图书馆、宗教场所——往往能更快地从灾害中恢复，但恢复程度有多大、又体现在哪些地方？你将构建空间数据管道，为数十座美国城市的公共空间打分，然后利用出行数据把这些评分与疏散行为和灾害暴露联系起来。工作内容涵盖 GIS 与空间统计、用于共享结果的仪表板和 API，以及一份把社区基础设施与应急准备联系起来的报告。

选课名额：5 名学生 数据管道 → 评分 → 报告
SYSEN 5900-664 课程编号 19055 🚲 共享单车

共享单车网络分析（Bikeshare Network Analytics）

网络大数据出行

当我们比较骑行者在美国各大共享单车系统中的移动方式时，会浮现出哪些规律？

美国每一座主要城市都运营着共享单车系统——Bluebikes、Citi Bike、Divvy、Capital Bikeshare——每个系统都记录着数百万次骑行。你将抓取这些记录，并用统一的数据模式把它们整合进一个可供分析的数据库，然后对由此产生的出行网络建模，研究骑行量、公平性与骑行者行为——这些是任何单一城市的数据都无法单独揭示的。工作内容涵盖网络科学、大规模数据抓取与数据库设计。

选课名额：5 名学生 抓取 → 统一 → 建模
SYSEN 5900-665 课程编号 19056 🌳 故障树

基于 FaultDB 的智能体故障树分析（Agentic Fault Tree Analysis with FaultDB）

可靠性安全智能体 AI

这个系统失效的概率有多大——又是哪些部件最为关键？

可靠性工程师花了太多时间与笨重的桌面工具较劲，只为回答一个问题：这个系统失效的可能性有多大，哪些部件最关键？你将扩展 FaultDB——一个把 R 分析引擎与 React 图形编辑器结合起来的浏览器平台——并加入智能体 AI 工作流，帮助用户构建故障树与攻击树、运行割集分析并解读结果。工作内容涵盖 LLM 智能体设计、可靠性建模、交互式前端，以及它们背后的 API。

选课名额：5 名学生 概念验证 → Alpha → Beta
SYSEN 5900-666 课程编号 19057 ☢️ SAFECAST

基于 SAFECAST 的开源辐射监测（Open-Source Radiation Monitoring with SAFECAST）

传感器开放数据危机响应

核灾难之后，一个开放的、由公民运行的传感器网络能否清晰、实时地告诉人们哪里是安全的？

SAFECAST 是一家总部位于东京的非营利组织，在 2011 年福岛核灾之后，建立了全球最大的本底辐射测量开放数据集——由公民使用手持和固定传感器众包采集，并免费向公众发布。如今他们的网络绘制了福岛、乌克兰以及全球各城市的地图，用以支持受辐射影响地区的危机追踪与恢复工作。在这项全新的合作中，你的团队将协助 SAFECAST 建设其全球传感器网络背后的仪表板系统与 AI 集成，使其能够在最关键的时刻向公众传递准确、公正的辐射信息。我们正在招募具备以下任一方面技能的学生：数据库、传感器工作、API、React、仪表板与数据可视化——你将交付一个可运行的工具以及一份报告。

选课名额：5 名学生 传感器 → 仪表板 → AI

我们正在寻找……

我们正在寻找有才华的编程者，运用你们的数据整理、数据可视化与数据传达技能，构建可运行的工具——什么适合解决问题就用什么：React、Python、R、SQL、云服务。并不要求你事先有使用我们特定技术栈的经验；我们会培训学生使用 API、仪表板和 GitHub，学生们将协作共同打造产品。我们的团队由计算机科学、系统工程以及其他工程专业的学生共同组成。

要求具备 R 语言的先修经验（例如 SYSEN 5300）或具备扎实的 Web 开发经验（例如 JavaScript、HTML、CSS）。所有学生都应准备好学习新技能。刚开始学编程？请做好自学的准备——并同时选修 SYSEN 5300（秋季 · R 语言基础）或 SYSEN 5381（春季）来提升技能。

出勤

  • 我们将大约每周集体会面一次，每位团队成员在会上分享自己的进展。

评分标准

交付成果（小组） — 60% 每周进度检查出勤 — 10% 每周进度检查得分 — 10% 海报展示 — 10% 期末报告 — 10%

60% — 交付成果（小组）

学生将在教师建议下，按自己的意愿分成若干小组，共同应对一系列有助于推进本项目的挑战。每个学生小组需在整个学期内产出 3 项交付成果。每项交付成果都应附有一份共同撰写的说明，描述该交付成果，篇幅至少 1 页、单倍行距（这些内容日后可以整合进一篇论文！）。每项交付成果占该学生团队成绩的 20%。学生将在每个截止日期前一个月，与项目导师共同确定下一项交付成果。

  • 20% — 交付成果 1：第 1 个月结束后提交，附说明。
  • 20% — 交付成果 2：第 2 个月结束后提交，附说明。
  • 20% — 交付成果 3：第 3 个月结束后提交，附说明。

10% — 参加每周进度检查（个人）

每周报名并参加至少 1 次与项目教师团队的进度检查会议。（强烈建议你每周与你的搭档报名同一时段的进度检查。）

10% — 每周进度检查得分（小组）

在每次检查会议上，学生需向项目导师汇报自己的进展。每次检查可能得到两种分数之一：有进展（100%）或无进展（0%）。每学期每位学生有 2 次"免罚"机会（即某一周可以没有进展），不影响成绩。在剔除 2 次"无进展"得分之后，你的每周进度检查得分将取平均值，作为这一部分的总评成绩。

10% — 海报展示（团队）

学期末，你的团队将制作一份面向公众的海报或视频（详情另行通知），用以展示本学期所完成的产品。

10% — 期末报告（团队）

学期末，你的团队需要向所在项目提交一份报告，总结你们在本硕士项目中所做的贡献。
